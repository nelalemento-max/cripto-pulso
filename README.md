# CriptoPulso

Aplicación educativa de análisis y práctica de criptomonedas para Vercel y Supabase.

## Configuración

Agrega en Vercel `NEXT_PUBLIC_SUPABASE_URL` y `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` para Production, Preview y Development.

El capital y las operaciones mostradas en el simulador son virtuales. No constituyen asesoramiento financiero.
